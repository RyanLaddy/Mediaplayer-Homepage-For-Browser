## ✨ Features

- 🎧 **Spotify Integration** — Track your listening activity through Last.fm.
- 🌐 **Custom New Tab** — Use the homepage as your browser's new tab page with a New Tab Override extension.
- ⚡ **No Downloads Required** — Get started without installing extra software for the homepage itself.
- 🔑 **Personalised Setup** — Connect your Last.fm username and API key.
- 🚀 **Simple Configuration** — Follow the setup guide below and get started in minutes.

## 🚀 Setup Guide

**Before you begin:** You'll need a Spotify account, a Last.fm account, a Last.fm API key, and a browser extension that lets you customise your new tab page.

### 1. Create a Last.fm Account

If you don't already have one, sign up here:

👉 [Create a Last.fm account](https://www.last.fm/join)

### 2. Connect Spotify to Last.fm

Link your Spotify account to Last.fm so your listening activity can be tracked.

👉 [Connect your music services](https://www.last.fm/settings/applications)

### 3. Get Your Last.fm API Key

You'll need an API key to allow the homepage to retrieve your listening information.

👉 [Get a Last.fm API account/key](https://www.last.fm/api/account/create)

**⚠️ Important:** Keep your API key safe. Don't publish private credentials or commit sensitive keys to a public GitHub repository.

### 4. Open the Homepage

Open the homepage and follow the prompts displayed on the right-hand side.

- Enter your **Last.fm username**.
- Enter your **Last.fm API key**.

Make sure both are entered correctly.

### 5. Set It as Your New Tab Page

Install or open your preferred New Tab Override browser extension and configure it to display this homepage.

Follow the extension's instructions to point your new tab to the homepage location.

### 6. You're All Set! 🎉

Open a new tab, complete any remaining prompts, and enjoy your personalised music homepage!

## ❓ Troubleshooting

<details>
<summary><strong>🎵 My Spotify listening activity isn't showing</strong></summary>

- Check that Spotify is linked to your Last.fm account.
- Confirm that Last.fm is receiving your listening activity.
- Make sure you're using the correct Last.fm username.
- Allow a little time for your listening activity to update.

</details>

<details>
<summary><strong>🔑 My API key isn't working</strong></summary>

- Check that you copied the entire API key.
- Make sure there are no extra spaces.
- Verify that you're using your Last.fm API key, not your Spotify credentials.

</details>

<details>
<summary><strong>🌐 My homepage isn't opening in a new tab</strong></summary>

- Check your New Tab Override extension settings.
- Verify that the homepage URL or local file path is correct.
- Make sure the extension is enabled in your browser.

</details>
